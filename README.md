# Student Grade Calculator 🎓

A simple Python program that calculates a student's total marks, average, grade, and pass/fail result.

## ✨ Features

- Takes the student's name as input
- Accepts marks for 5 subjects
- Calculates total marks
- Calculates average marks
- Assigns a grade
- Displays Pass or Fail result

## 🛠️ Technologies Used

- Python

## ▶️ How to Run

1. Make sure Python is installed.
2. Open the project in VS Code.
3. Open the terminal.
4. Run:

```bash
python grade_calculator.py
